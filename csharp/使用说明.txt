上班鼓励器 C# 版（.NET Framework 4.0 / WinForms）
====================================================

## 运行

双击 `上班鼓励器_CSharp.exe` 即可。

要求：Windows 7 SP1 及以上（Win7 SP1 自带 .NET Framework 4.0，早于 4.5），
若是原始 Win7 未装 SP1，需先安装 .NET Framework 4.0（微软官网可下载）。
Win8 / Win8.1 / Win10 / Win11 也都能直接运行。

## 与 Go 版一致的功能

- 默认窗口 270×335（放大留白、字号更宽松，兼容字体偏大的电脑），薄荷绿主题，与 Go 版界面布局相同（时间/状态在左，今日已赚在右）
- 今日已赚金额按秒更新；下班倒计时、工时进度条、本月累计
- 鼓励语：按今日已赚计算「今天的价钱能买什么」，44 种便宜好物随机轮换（每 12 秒）
- 换肤（薄荷绿/奶油黄/樱花粉/雾霾蓝/紫罗兰）、置顶/取消置顶、暂停计时、设置面板
- 设置保存到 exe 同目录 `config.json`，重启后保留用户设置；删除该文件恢复默认值
- 内置薄荷绿 ¥ 图标（任务栏、标题栏可见）

区别：Win7 不带 emoji 字体，按钮文字中的 emoji 换成了纯文字（如「关闭计时器」「换肤(薄荷绿)」）。

## 编译（如需自行修改）

在装有 .NET Framework 4.0 的 Windows 上，用 Visual Studio 2010/2012/2013（或任意支持 C# 5 的编译器）
新建 .NET Framework 4.0 WinForms 项目，把 `Program.cs` 加入项目，把 `app.ico` 设为应用程序图标即可。

本 exe 由 Roslyn 编译器以 C# 5 语法、.NET 4.0 引用程序集编译，已验证：
mscorlib / System.Windows.Forms / System.Drawing 引用版本均为 4.0.0.0。
